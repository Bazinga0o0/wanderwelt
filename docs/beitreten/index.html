wanderwelt beitreten

wanderwelt ist ein Programm für Windows. Lade es herunter und starte die Datei wanderwelt.exe.

wanderwelt herunterladen

Du brauchst zum Beitreten einen Gruppencode von deinem Admin (oder von einem Mitspieler). Ohne diesen Code kannst du der Gruppe nicht beitreten.

Öffne wanderwelt …

Dein Browser fragt eventuell, ob wanderwelt geöffnet werden darf. Bestätige das mit „Öffnen“.

wanderwelt wurde geöffnet. Du kannst diesen Tab schließen.

Hat sich nichts geöffnet? wanderwelt ist noch nicht installiert.

wanderwelt herunterladen
  1. Die heruntergeladene wanderwelt.exe starten (Windows warnt eventuell, weil die Datei nicht signiert ist: „Weitere Informationen“, dann „Trotzdem ausführen“).
  2. Die Einrichtung führt dich durch alles; dort fügst du den Gruppencode ein und legst ein Konto an.
  3. Der Admin nimmt deine Anfrage an, danach kannst du spielen.

Diese Seite speichert nichts, lädt nichts nach und schickt nichts an einen Server. Sie öffnet nur den Link wanderwelt://beitreten, der keine Daten enthält.
